# Site typography

These local WOFF2 files preserve the existing Cormorant Garamond, Inter,
Bodoni Moda and Bodoni Moda SC families. Latin and Latin Extended subsets cover
the site's French text. The Bodoni families are only needed on the About page.

Generated from the Google Fonts CSS API by `node scripts/vendor-fonts.mjs`.
Content-hashed filenames can be safely cached; regenerate intentionally, not
during the deployment build. Original font projects are distributed under the
SIL Open Font License; the accompanying OFL files are kept in this directory.
